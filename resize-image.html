How to resize an image

Select a JPG, PNG or WebP image, enter the width or height you need, and keep the aspect ratio option enabled if you want to avoid stretching the image. Then click Resize Image and download the result.

What does aspect ratio mean?

Aspect ratio describes the relationship between an image's width and height. Keeping the original aspect ratio prevents the image from looking stretched or compressed.

Does resizing reduce file size?

Often yes. Reducing the pixel dimensions of an image usually reduces the amount of image data and can make the resulting file smaller. The exact result depends on the image format and image content.

Are my images uploaded?

Image resizing is performed in your browser using the HTML canvas. The tool does not intentionally send your image to an image-processing server.
