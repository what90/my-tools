How to use this tool

  1. Choose a supported image, or try the sample above.
  2. Choose JPG, PNG or WebP. Quality applies to JPG and WebP.
  3. Run the tool. Compare the preview, dimensions and size, then download.

Before you convert

  • JPEG has no transparency: transparent areas are filled with white.
  • Animated inputs become a still image. Editing metadata is not preserved by this tool.
  • Keep important originals. Format conversion and enlargement cannot restore lost detail.

Questions about the tool

Are my images uploaded?

The tool processes selected image files in your browser. The website itself still contacts its hosting provider and may load Google advertising services; see the Privacy page.

Why is the result larger?

The source may already be well compressed. A different format or encoder can create a larger file. The result always shows the actual change; try another format or reduce dimensions.

Why does PNG ignore the quality slider?

The browser PNG encoder uses lossless storage and ignores this lossy quality setting. This tool is not a specialized PNG optimizer. Resize or try WebP when a smaller file matters more.
