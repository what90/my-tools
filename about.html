About FastImgConvert

FastImgConvert is a small set of free browser tools for a common problem: an image is in the wrong format, too large, or the wrong pixel dimensions.

Three tools, three different decisions

  • Converter: create JPG, PNG or WebP files from supported source images.
  • Compressor: compare output size at a chosen format and quality.
  • Resizer: set width and height while optionally keeping the original proportions.

These tools run on selected images in your browser. No account or paid plan is required. The image-processing code does not upload selected file contents to a conversion server. The website and advertising services can still make ordinary network requests; the privacy page explains that distinction.

What this site can and cannot do

The tools use the browser's image decoder and canvas encoder. Outputs depend on browser support and available memory. The current limits are 25 MiB per file, 24 megapixels, 12,000 pixels per side and 20 files per batch. Resizing accepts one image at a time. The limits reduce the risk of exhausting a device's memory; they are not a guarantee that every allowed file can be processed.

The tools do not restore lost detail, preserve animations, guarantee exact file sizes, or replace specialist RAW, print or archival software. Keep important originals.

How the examples are made

The examples page provides source files, actual converted files, dimensions and exact byte counts. Its test chart and transparent badge were created for FastImgConvert. The method and encoder used for those measurements are stated beside the results.

How to investigate a failed conversion

Try the bundled sample first. If the sample works but your file does not, check its format, byte size and dimensions. If the browser reports unsupported decoding, export the file to PNG or JPG in an application that can open it, then try again. A file extension alone does not prove what data a file contains.

For a surprising output size, follow the compression workflow and compare the source and result at full size.
