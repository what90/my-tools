Image conversion examples: real files, real sizes

These are actual files made by FastImgConvert's conversion engine, not estimated savings. Download the source and results to judge the changes yourself.

Reference run: September 12, 2026 · Chromium 153.0.8010.0 · FastImgConvert image-engine.js · canvas.toBlob

The chart and badge are synthetic images created for this comparison. They test text, gradients, texture and transparency; they do not represent every photograph. Your browser and images may produce different results.

1. The same image at different quality settings

The source combines a smooth color gradient, thin white curves, a grayscale strip, small text and a detailed texture. Each file below was exported directly from that source. Pixel dimensions stayed at 1,200 × 800.

What these numbers tell us

For this source, JPG at quality 95 is larger than the original PNG. Re-encoding as PNG is also larger. Neither operation is guaranteed to reduce file size. WebP at quality 80 is smaller than JPG at quality 80 here, but identical quality numbers across formats do not mean identical perceived quality.

Open or download the samples at full size and compare the small text, curves and textured panel. The reduced previews above make some changes harder to see. Choose the smallest result that still works for your intended use.

2. Fewer pixels, with quality held constant

Both of these JPGs use quality 80 and were created directly from the same original PNG. Halving both dimensions reduces the pixel count from 960,000 to 240,000. In this example, the smaller image uses 65.8% fewer bytes than the full-size JPG.

Smaller dimensions are useful when the destination does not need all the original pixels. They are not suitable when the full-resolution detail is required. Try the resizer with the ratio lock on.

3. What happens to a transparent background

The source badge includes a fully transparent border and a partly transparent outer circle. The browser's JPG output has a white background because JPEG cannot store transparency. The WebP output keeps transparency. The preview checkerboard is added by the page, not baked into the transparent files.

Compare the partly transparent outer circle against the background where you plan to use the badge. A small file with the wrong background is not the right delivery file.

Reproduce a comparison

  1. Download the original test chart from the table, or choose Try the sample image in a tool.
  2. Select the listed output format and quality. Keep the dimensions unchanged for the first table.
  3. Run the conversion and compare the downloaded bytes and visible detail.
  4. For the resize test, start from the original again, enter 600 × 400 pixels and choose JPG quality 80.

Browser versions may use different encoders, so an exact byte-for-byte match is not required. The important controls are the same source, dimensions, format and quality. No external conversion service was used for the reference outputs.
