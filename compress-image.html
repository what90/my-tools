What does image compression do?

Image compression reduces file size so images can load faster, use less storage, and upload more quickly. Lower quality settings usually create smaller files, but excessive compression may reduce visible image detail.

Choosing the right quality

For most photos and web images, starting around 75–85% is a practical balance. If the image still looks good, lowering the setting further can reduce the file size.

Frequently asked questions

Are my images uploaded?

Compression is performed in your browser using browser image-processing capabilities.

Does compression reduce image quality?

It can. Lower quality settings usually create smaller files but may remove more visual detail.

Why is a PNG sometimes not much smaller?

PNG compression behaves differently from JPEG and WebP. Some PNG images may not shrink much when processed in the browser.
