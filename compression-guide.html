Reduce image file size without guessing

A useful compressed image must be small enough for its destination and clear enough for its job. Check both before replacing a file.

Updated September 13, 2026 · Companion to the image compressor and resizer

Start with the destination's actual requirement

An upload form may limit bytes, pixel dimensions, file types, or all three. Read the form first. A 400 × 400 pixel requirement is different from a 400 KB limit. FastImgConvert displays KiB and MiB: 1 KiB is 1,024 bytes and 1 MiB is 1,048,576 bytes. Some websites use decimal KB and MB instead, so leave room below the stated limit.

A practical sequence

  1. Keep the source. Save a delivery copy instead of overwriting the original.
  2. Set useful dimensions. If a website only needs 1,200 pixels across, a much wider image can use unnecessary storage. Use the resizer and keep the aspect ratio unless you deliberately want distortion.
  3. Choose an accepted format. Use JPG when the destination requires it. Try WebP if it is supported. Preserve transparency with PNG or WebP.
  4. Try a quality setting. Start at 80–85 for JPG or WebP, then inspect the output. The number is not a measurement of perceived quality.
  5. Check the downloaded file. If it still exceeds the limit, return to the original and lower quality or dimensions. This tool does not promise an exact target byte size.

Why pixel dimensions often matter more

Changing 1,200 × 800 pixels to 600 × 400 gives one quarter as many pixels, not one half. The file size will not necessarily fall by exactly 75%, because the format, content and encoder also matter. The measured resize example shows actual outputs at both sizes.

Why the PNG slider is disabled

The browser's PNG encoder does not use the JPG/WebP quality parameter. Re-saving a PNG can produce the same size or a larger file, especially if the source was already optimized. This tool does not perform palette reduction or specialized PNG optimization. If you need a smaller transparent graphic, try smaller dimensions or WebP and inspect its edges.

Compare the detail that matters

  • Documents and screenshots: read the smallest text at full size.
  • Portraits: inspect eyes, hair and skin texture.
  • Logos: check narrow lines and transparency against the intended background.
  • Gradients: look for banding, blocks or halos around edges.

When the result gets larger

That is a valid result, not necessarily a processing error. The original may have used a more efficient encoder or a lower quality setting. Converting a compact JPG into lossless PNG can increase storage substantially. The tool reports the actual size change and provides both original and result downloads, so you can keep the file that suits your task.
