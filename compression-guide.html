Image compression guide

Image file size is influenced by pixel dimensions, format, image complexity and encoder settings. A single quality percentage cannot guarantee a particular file size, so the best workflow is to make a conversion and inspect both the result and its size.

Quality is not the same as resolution

Resolution describes pixel dimensions such as 1920×1080. A quality control for JPG or WebP changes how aggressively the encoder represents those pixels. Lower quality can reduce storage without changing dimensions, although fine detail may become less accurate.

A practical workflow

  1. Keep the original file as a backup.
  2. Choose the format required by your website, application or recipient.
  3. Start with a moderate-to-high quality setting such as 80–85 for a lossy output.
  4. Inspect text, faces, gradients and high-contrast edges.
  5. If the file is still too large, lower quality gradually and compare again.

Why PNG behaves differently

PNG is lossless, so a JPEG-style quality slider is not a direct measure of PNG visual quality. PNG is excellent for graphics that need exact edges or transparency, but it may be inefficient for photographs.

Avoid repeated lossy conversions

Repeatedly decoding and re-encoding a lossy image can compound artifacts. If you expect to edit an image again, retain the original source and create delivery copies from that source.
